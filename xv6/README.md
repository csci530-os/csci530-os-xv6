# Xv6 Repositories

The Xv6 source repositories for the code, and the companion
textbook will reside here.

- [xv6-riscv code repository](https://github.com/mit-pdos/xv6-riscv)
- [xv6-riscv-book](https://github.com/mit-pdos/xv6-riscv-book)

**Note**: This directory initially is empty, containing only some
Makefile build patches in the `patch` subdirectory.  Read the
top-level `README.md` instructions and use the `make setup` command
to clone and setup the xv6 source code and book repositories
here.
